# Maintenance and Attribution

[← Back to README](../README.md)

This note keeps two things distinct: the original academic project, and the later work of preparing
and maintaining this repository.

## Original academic project — 2025

The comparator project was completed collaboratively by **Group 7** of the Department of Computer
Science and Engineering, East West University, for CSE345 — Digital Logic Design (Summer 2025,
Section 6), under Nishat Tasnim. It was submitted on September 2nd, 2025.

| Member | Recorded involvement |
|---|---|
| Nafis Afzal | Simulation development and related visual material |
| Anik Saha | Simulation development and related visual material |
| Ashiqur Rahman Sohan | Collaborative project work |
| Raiyan Fardin Haque | Collaborative project work |

The project as a whole — problem analysis, derivation of the comparison conditions, the report and
the hardware implementation — was joint work. The original report does not record a finer
per-member breakdown, and none is claimed here.

## Repository enhancement and maintenance — 2026 onward

**Repository enhancement, documentation organization, visual presentation, and publication
maintenance by Nafis Afzal.**

| Activity | Scope |
|---|---|
| README redesign | Rebuilt as an illustrated project landing page while preserving the factual academic content |
| Documentation organization | Added and structured the technical documents under `docs/` |
| Visual presentation | Selected, captioned and linked genuine project images; created the visual gallery index |
| Repository structure | Established the current layout of reports, source, documentation and assets |
| Verification and publication | Re-ran the HDL testbench, maintained the private two-branch repository and verified published content |

The self-checking testbench in `src/tb/comparator_4bit_tb.v` is identified in its own header and in
[Testing and Results](TESTING_AND_RESULTS.md) as new 2026 work by Nafis Afzal; it was not part of the
September 2025 submission.

## What this distinction does not change

- It does **not** transfer ownership of the original academic work to any single person.
- It does **not** claim that the comparator implementation, hardware work or report was produced
  exclusively by Nafis Afzal.
- It does **not** add contributions that are not supported by the repository history or the
  existing documentation.
- It does **not** alter the team list, course details or submission date.

The enhancement describes preparation and presentation of the repository, not authorship of the
original engineering project.
